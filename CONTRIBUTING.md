# Contribuer

1. Partir de `develop` : `git checkout develop && git pull`
2. Créer une branche : `git checkout -b feature/nom-court`
3. Commiter avec un préfixe : `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`
4. Pousser puis ouvrir une Pull Request **vers `develop`** (jamais vers `main`)
5. Attendre la relecture de l'autre membre avant de fusionner

Règles : aucun mot de passe dans le dépôt ; seul le responsable de `pom.xml` et `persistence.xml`
les modifie, l'autre propose ses ajouts par une petite PR.
